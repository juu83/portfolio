# Portfolio - Julie Doubre

Ce dépôt contient le code source de mon portfolio personnel. Ce site web présente mon parcours professionnel, ma formation ainsi que les différents projets sur lesquels j'ai eu l'opportunité de travailler.

## Technologies utilisées

Ce projet est un site web statique et léger, développé sans framework :
- **HTML5** : Structure de la page
- **CSS3** : Mise en page et style
- **JavaScript** : Interactivité et dynamisme

## Structure du projet

- `index.html` : Point d'entrée et structure principale du site.
- `style/style.css` : Fichier contenant l'ensemble des règles de style.
- `js/script.js` : Scripts gérant le comportement dynamique de la page.
- `assets/` : Dossier contenant l'ensemble des ressources statiques :
  - `img/` : Images, logos des entreprises/écoles et icônes.
  - `fonts/` : Polices de caractères personnalisées (ClashDisplay).
- `favicon.png` : Icône du site pour le navigateur.
